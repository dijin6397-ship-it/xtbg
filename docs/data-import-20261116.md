## 处理规则

- 员工按 `employee_code` 匹配；命中者更新角色、模块关联与 `task_import` 权限，**保留库内更详细的职位名称**。
- 未命中的 3 名员工新建账号：杜建鑫、陈宇杰使用拼音用户名，张文严使用员工编号。
- 账号密码统一重置为约定初始密码（不在此文档记录，见运维交接）。
- WBS 按 `code` 匹配，已存在则复用节点、仅补充缺失车号；Excel 中 N-A100 / N-A103 存在重复车号，按去重后写入。

## 执行方式

1. `systemctl stop collab-platform` 停机，避免写入与内存库互相覆盖。
2. 备份：`cp /opt/server/data.db /opt/backups/manual-<时间戳>.db`。
3. 用 sql.js 脚本在库副本上执行导入，产出 `/tmp/data.db.new`。
4. 校验：用户数 / 角色分布 / 密码可用性 / WBS 层级与车号数 / 权限人数全部比对通过。
5. 覆盖 `/opt/server/data.db`，`chown root:root`、`chmod 644`，启动服务。
6. API 端复核：`POST /api/auth/login` 新旧账号均可登录；`GET /api/wbs/tree` 返回 33 个项目、90 个子节点。

> 导入必须在持久化修复已生效的前提下进行，否则重启后数据会退回内存外的旧库。
